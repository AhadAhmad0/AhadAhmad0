## Projects

- [Fraud Detection with LLM Explanations](https://github.com/AhadAhmad0/fraud-detection-llm-explainer): XGBoost flags the transaction, SHAP finds the reasons, and an LLM turns them into plain English. The LLM never makes the decision. [Live demo](https://fraud-detection-llm-explainer.streamlit.app/)
- [Brain Tumor Classification](https://github.com/AhadAhmad0/brain-tumor-classification): a 4-class MRI classifier. A Grad-CAM study suggests it relies on skull borders, not tumor tissue. The README covers three fixes that did not work. [Live demo](https://huggingface.co/spaces/AhadAhmad0/Brain-Tumor-Classification)
- [Crop Disease Detection](https://github.com/AhadAhmad0/crop-disease-detection): a leaf disease classifier for 5 crops, with Grad-CAM heatmaps, a severity grade and treatment tips. [Live demo](https://huggingface.co/spaces/AhadAhmad0/crop-disease-detection)
- [Blinkit Sales Dashboard](https://github.com/AhadAhmad0/blinkit-sales-dashboard-powerbi): a Power BI dashboard on grocery sales data.
